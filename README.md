# Customer-Churn-Analysis-Using-MySQL

## Project Overview

This project focuses on analyzing an e-commerce customer churn dataset using MySQL. The project covers data cleaning, handling missing values, standardizing inconsistent data, transforming columns, and performing SQL-based analysis to identify customer churn patterns and generate useful insights.

## Objectives

* Clean and prepare the customer churn dataset for analysis.
* Handle missing values using mean and mode imputation.
* Remove unwanted records and standardize inconsistent values.
* Create meaningful categories and derived columns.
* Analyze customer churn, complaints, payment preferences, order behavior, and customer characteristics.
* Use SQL queries to generate insights from customer data.

## SQL Concepts Used

* SELECT, WHERE, and filtering
* UPDATE and DELETE
* ALTER TABLE
* GROUP BY and ORDER BY
* Aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, and `MAX()`
* `CASE` statements
* `COALESCE()`
* Subqueries
* User-defined variables
* Conditional calculations
* INNER JOIN
* Creating and inserting data into tables

## Data Cleaning

* Handling missing numerical values using mean imputation.
* Handling missing values using mode imputation.
* Standardizing inconsistent values.

## Data Transformation

* Renaming columns for consistency.
* Creating `ComplaintReceived` based on complaint information.
* Creating `ChurnStatus` to classify customers as Active or Churned.

## Analysis

* Churned and active customer counts.
* Average tenure and cashback of churned customers.
* Complaint percentage among churned customers.
* Customer distribution by city tier.
* Preferred payment modes.
* Order behavior and coupon usage.
* Satisfaction scores.
* Preferred order categories.
* Average cashback by order category.
* Customer return information using joins.

## Key Learning

Through this project, I gained practical experience in using MySQL for data cleaning, transformation, and exploratory analysis. It helped me understand how SQL can be used to turn raw customer data into meaningful information for business decision-making.
